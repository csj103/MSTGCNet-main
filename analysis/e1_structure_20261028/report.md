# E1 变量级表示退化：现有结构检查

日期：2026-10-28。范围：检查既有 E0–E5 结果和 E1 结构，未改生产代码、未更新权重、
未重训，也没有替换原异常分数/阈值。所有新增文件均在本分析目录内。

## 结论先行

**层间传递正确；当前最需要排查的是 E0→E1 同时改变了多个结构因素，不能将下降
单独归因为“保留物理变量维”或“d_var=16太小”。**

本轮确认四类值得隔离的差异：

1. 共享三点线性编码器没有显式长趋势表示，真实数据分量相对 PE 的比例也改变。
2. 移除了图前可学习的跨变量特征融合，却让 E1 的首次物理变量交流依赖固定随机二值图。
3. 新路由先逐变量提取、再固定等权平均，实际后两层路由及专家贡献明显改变。
4. `circular→replicate` 正好改变最后评分位置读取的时间点，是此前被低估的边界混杂。

此外，attention/FFN/LN/head/temporal residual/参数分配均发生变化。
这是当前实现的诊断，不是对“变量级表示必然无效”的结论。

## 2. 逐变量时间编码器：会保留局部变化，但不能等同于丰富时序提取

源码：`models/variable_granger.py:19-30`。

```text
RevIN [B,L,V]
 → [B*V,1,L]
 → 共享 Conv1d(1,16,kernel=3,padding=replicate,bias=True)
 → [B,L,V,16] + 每变量身份向量 + 共享时间位置编码
```

在非边界位置，输入相关分量就是
`H[t,v,:] = W[-1]*X[t-1,v] + W[0]*X[t,v] + W[1]*X[t+1,v]`，
加上固定于该变量/时间索引的bias、identity与PE。编码器本身没有非线性、叠层、
多尺度或长时间卷积。所有变量使用同一组滤波器；身份向量不会把这些滤波器变成
变量专用时间编码器。

在20Hz下，内部位置的三点首尾跨度为0.10秒。实际评分末点使用复制边界，只有
`[X94,v, X95,v, X95,v]`，不是三个不同时间点。

但不能说编码器完全无法提取变化：训练后的16×3卷积核矩阵rank=3，奇异值约
`[1.6395,1.4270,1.1071]`，条件数1.4809；在减去已知固定偏置后，三点均值/差分可由
线性读出恢复，数值误差约2e-16。局部信息没有因卷积核坍缩而被直接压没。
这不证明现有模型已经学会使用这些差分，也不证明长趋势建模足够。

128个正常窗口中的训练子集统计：E1内容分量RMS=0.5990，PE=0.7071，conv bias=0.3651，
identity=0.0294；E0内容RMS=1.1857，PE=0.7071。
新表示的内容/PE幅值比明显变化，且缺少E0的可学习conv_scale。
这种比例差异值得隔离检查，但不能仅凭幅值宣称PE造成性能下降。

E1内容通道的经验协方差有效rank约1.076，反映这批正常三点输入的高相关性及共享线性展开。
它与E0的rank不可直接作为整体容量比较，因为E1仍保留10个变量轴，而E0把它们混合。

专家内部仍有0.1～1.6秒多尺度Patch attention与后续图传播；路由还有整窗口DFT/趋势处理。
因此“整个网络没有趋势/长时信息”是错误表述。
关键区别是：`GMoEBlock.forward:330`丢弃router的第三个增强特征输出，
**季节/趋势处理主要服务于门控，并没有把这份增强表示直接传给专家。**

## 3. d_var=16：有容量与约束变化，但还没有16对32的性能证据

E1每时刻有10×16=160个隐藏坐标，E0有64个混合坐标，不能因为16<64就断言总表示更窄。
真正改变的是共享方式、每个节点attention宽度和变量交互位置：

| 项目 | E0 | E1 |
|---|---|---|
| Patch attention宽度/每头 | 64 / 32 | 16 / 8 |
| 局部attention前后投影 | 1→64→1 | 直接16维attention |
| temporal residual | 无直接x+attn | x+attn |
| LN/FFN作用轴 | 每时刻64维混合特征 | 每变量16维，变量间共享FFN |
| FFN | 64→128→64 | 16→128→16 |
| 图后变量投影 | to_model(V→64) | 只重排还原，无dense变量融合 |
| 输出头 | 每个变量独立64维权重 | 所有变量共享16→1 |

参数分配比总参数更值得注意：

| 模块参数 | E0 | E1 |
|---|---:|---:|
| 输入编码器 | 1,921 | 224 |
| Patch attention及相关投影 | 201,996 | 13,056 |
| FFN | 198,912 | 50,880 |
| 跨变量投影 | 16,248 | 0 |
| 重构头 | 650 | 17 |
| graph_bias | 11,520 | 184,320 |
| 总参数 | 463,144 | 336,938 |
| 扣除对应模式明确不可微/未使用参数 | 451,624 | 254,762 |

E1约72.35%的上述可微路径参数是固定节点/位置的graph_bias。
这些bias可学习偏移/位置模板，不能视作同等数量的数据相关时序特征提取参数。
因此总参数数目会掩盖attention/FFN/head能力和归纳偏置的变化。

六组正式实验全部d_var=16，没有32维重训结果。
仅构造32维架构时，总参数682,298，可微路径529,466，attention50,688、FFN100,224；
这些只是静态计数，不是32维性能结果。
增加到32不会扩大编码器三点感受野，局部线性输入rank上限仍为3；
它会扩大后续attention/FFN容量。故“编码器时序不足”和“专家宽度不足”需要分开验证。

## 4. 每层GMoE确实处理上一层更新后的变量特征：通过

源码：`VariableModel.forward:181-190`及继承的`GMoEBlock.forward:329-358`。

在64个正常训练窗口、64个正常验证窗口上用forward hook核验：

- 三层输入/输出均为`[B,96,10,16]`。
- 第2层输入与第1层输出、第3层输入与第2层输出逐元素完全相同。
- 训练窗口三层相对更新RMS约为`1.0170 / 0.5565 / 0.3656`，均有实际更新。
- 没有发现每层重新使用固定原始X、层间变量维丢失或没有更新的问题。

这一项已可排除，不应作为下一步主要修改方向。

## 5. 新路由器显著改变分配与融合贡献：有实际证据

源码：`VariableRouter._routing_features:33-41`。
先把每个变量作为独立样本，用共享参数做DFT/趋势/投影，然后对10个标量路由轨迹等权平均。
原噪声门控、Top-K和负载均衡形式仍在，但输入统计及信息压缩方式变了。
最终等权均值不是可学习的变量重要性聚合，变量之间的不同响应可能互相抵消。
identity可以通过共享非线性趋势处理间接影响路由，故不能绝对说路由完全丢掉变量身份。

在保留PE/bias/identity的零输入反事实中，第一层数据相关路由响应经变量平均后的RMS，
相对各变量响应合并RMS约为训练0.309、验证0.305。
这个指标衡量均值压缩，不是性能下降幅度，且反事实经过非线性操作，不是可加因果分解。

最佳checkpoint在64个正常训练代表窗口上的平均gate：

| 层 | E0平均gate（专家0～3） | E1平均gate（专家0～3） |
|---|---|---|
| 1 | [0.8632,0.0558,0.0055,0.0755] | [0.8456,0.0838,0,0.0706] |
| 2 | [0.8108,0.0040,0.0491,0.1361] | [0.0548,0.8730,0.0722,0] |
| 3 | [0.4691,0.0261,0.4789,0.0260] | [0.0434,0.9050,0.0007,0.0510] |

E0最后层主要融合patch2与patch8；E1最后层约90.5%权重集中于patch6专家。
前两层E0也有主专家，不能泛称“E0均衡而E1塌缩”；显著差异主要在后两层，特别是最后层。

十轮训练统计也支持后层gate熵更低：最后轮第3层E0=0.9171、E1=0.4851。
但每个专家在训练中都被大量选择，不支持“专家完全饿死”。
训练期带噪声选择次数、平均门控权重、eval代表窗口分布是不同量，不能混用。

## 6. 图前交互：第一层专家特征完全逐变量，路由控制有全变量依赖

E0先通过Conv(V→64)混合变量，再通过to_vars(64→V)生成伪变量节点，
图前已经有多次可学习的跨变量信息混合。
E1的encoder、Patch划分、Patch attention都逐变量；第一次显式变量数值融合出现在图传播。
共享参数意味着不同变量共同参与学习同一套滤波器，不等于同一窗口里交换变量观测值。

合成受控扰动只改变变量3：

- 编码器其他变量变化最大值=0。
- 第一层专家图前时间编码其他变量变化最大值=0。
- 图后专家输出的其他变量变化最大值约0.0963，确认图传播承担首次特征交流。

但全窗router汇总全部变量，专家选择/权重因此有全变量控制依赖；
**不能把“图前没有跨变量特征融合”说成“整个模型图前没有任何变量依赖”。**
第2、3层也已经接收过前层图传播结果，不是每层都从互不相关的原始变量重新开始。

更重要的是E1首次交流依赖的图：

- `_adjacency`取固定随机node_embeddings的cosine Top-K索引，scatter常数1。
- 图不随当前输入变化；sim数值被丢弃，索引不可微。
- 实际反向探针确认adj.requires_grad=False，12组node_embeddings均无梯度；
  E1不使用的24个Q/K权重也无梯度，encoder和实际图传播参数仍有梯度。
- 该算法同样存在于E0，不是新出现的autograd bug；但E0节点值已混合全部变量，
  E1节点是真实物理变量，所以固定随机边约束的信息语义不同。
- 两个实际checkpoint的图拓扑也不相同。第一层p8专家每行5邻居平均只共有0.617条，
  120行的邻居集合均变化；不能把“同seed、同算法”理解为“同一张图”。

“图前保留真实变量身份”符合原研究要求，本身不是实现错误。
风险在于删除早期联合表示后，E1没有用可学习关系图充分补回变量联合建模能力。
E2的改善支持继续检查这一环节，但并没有恢复E0性能，不能称它是唯一原因。

## 7. 新发现：卷积边界改变了实际评分点的时间上下文

源码：E0 `MSTGCNet.py:378-385`，E1 `variable_granger.py:22`。

```text
E0最后一点的卷积输入：[X94(全部变量), X95(全部变量), X0(全部变量)]
E1最后一点的卷积输入：[X94,v, X95,v, X95,v]
```

E0的circular在末点引入窗口首点，即约4.75秒前的观测；E1的replicate复制当前末值。
这不是窗口外未来泄漏，但意味着两者最后点评分的直接编码上下文不等价。
原始encoder内部都叫kernel3，并不能消除这个差异。

在同128个正常窗口上：

| 指标 | E0 | E1 |
|---|---:|---:|
| 整窗SSE均值（原训练loss） | 1.4669 | 1.7500 |
| 最后位置MSE均值 | 0.016275 | 0.002524 |
| 最后位置/中间位置MSE | 13.76倍 | 1.45倍 |
| 最后位置占整窗SSE | 11.09% | 1.44% |

因此E1整窗重构误差略高19.3%，但实际causal_last位置正常误差低很多，
不能只用“整体欠拟合”概括，也不能把较低末点误差直接当作异常检测改善。

冻结权重，只在内存临时切换padding，最后恢复且预测逐元素恢复：

| 冻结模型算子切换 | 最后位置MSE |
|---|---:|
| E0 circular→replicate | 0.016275→0.003093，下降81.0% |
| E1 replicate→circular | 0.002524→0.039922，增至15.82倍 |

这是较强的边界敏感性证据，但切换可能形成分布外表示，未重新训练，
也没在此诊断中计算新的test AP/F1，**不能据此断言padding就是退化原因**。

还必须避免一个错误推理：绝对分数变小并不自动导致ATSSD召回下降。
原ATSSD对正比例缩放具有尺度一致性；把E0保存分数整体乘0.125后，
阈值恰好同倍缩放，预测逐点完全不变。ROC/AP的排序也不因正比例缩放改变。
需要隔离的是边界导致的分数形状、正常/异常分离与上下文变化，不是单纯幅值。

## 8. 检查结论与后续隔离顺序

| 用户检查项 | 结论 | 证据级别 |
|---|---|---|
| 局部变化/趋势编码是否充分 | 局部三点信息可保留；编码器本身缺少丰富非线性与长趋势，专家/路由另有时序能力 | 结构事实+局部探针；充分性未证明 |
| d_var16是否不足 | attention/FFN/head确实收缩且共享方式改变；没有16/32重训对照 | 容量差异已证，性能因果未证 |
| 每层是否使用更新特征 | 是，维度/层间相等/实际更新均通过 | 已排除该实现错误 |
| 路由输入是否改变分配 | 是，尤其最后层从双主尺度变为patch6主导 | 已有checkpoint与日志证据 |
| 图前是否缺乏变量交流 | 第一层特征路径是；路由有全变量控制，第2/3层已有前层图信息 | 已用扰动验证并限定范围 |

先把当前E1标记为“变量级结构整体改造”，不要把它当作只改一个变量维度的干净对照。
下一步若继续实验，建议按单因素顺序隔离，而不是同时修改所有可疑模块：

1. 控制encoder边界、初始化/scale与causal_last位置效应，先分离这项混杂。
2. 检查变量等权平均路由的贡献，单独比较路由接口；保持专家表示和图不变。
3. 再在完全相同其余结构下从头训练d_var16/32，报告有效参数与算力；
   不把旧16维checkpoint硬载入32维模型，不把不匹配权重的推理称为容量消融。
4. 单独核查共享滤波、共享输出头、attention/FFN宽度及静态图语义。
   维持真实变量token与索引，不能为了恢复交互又退回无约束V→64→V映射。

具体哪项导致多少AP损失，现有六组实验还不能识别。
当前没有完整train/val loss曲线与最佳epoch，所以也不能决定应增加epoch或宣称过拟合。
无需修改已通过的层间传递逻辑；也没有证据支持此时叠加新损失或只调大Granger强度。
